# OCR処理開始スクリプト

`start_ocr.py`は、アーセナルベースのカードOCR処理を簡単に開始するためのスクリプトです。

## 使用方法

### 1. 準備

```bash
# APIキーを設定
echo "your_openai_api_key_here" > APIkey.txt

# 依存関係をインストール
pip install openai
```

### 2. 実行

```bash
# 簡単実行
python3 start_ocr.py
```

## 機能

- **自動チェック**: APIキー、カードデータ、依存関係を自動確認
- **安全な設定**: API制限を考慮した適切な遅延設定
- **エラーハンドリング**: 分かりやすいエラーメッセージ
- **進捗管理**: 中断・再開機能付き

## 設定

スクリプト内で以下の設定が適用されます：

- バッチサイズ: 5件
- カード間遅延: 2秒
- バッチ間遅延: 10秒
- ログレベル: INFO

## 出力

- **OCR結果**: `ocr_results/`ディレクトリ
- **ログファイル**: `logs/`ディレクトリ
- **進捗ファイル**: `ocr_progress.json`
- **統計ファイル**: `ocr_stats.json`

## トラブルシューティング

### よくある問題

1. **APIキーエラー**
   ```
   ❌ APIキーファイルが見つかりません: APIkey.txt
   ```
   → `APIkey.txt`ファイルを作成してAPIキーを設定

2. **カードデータエラー**
   ```
   ❌ カードデータディレクトリが見つかりません: all_cards_list
   ```
   → 先に`fetch_cards.py`を実行してカードデータを収集

3. **依存関係エラー**
   ```
   ❌ openaiライブラリがインストールされていません
   ```
   → `pip install openai`でインストール

## 注意事項

- 処理には長時間かかります（2,355枚のカード）
- 中断する場合は`Ctrl+C`を押してください
- 進捗は自動保存されるので再開可能です
- API使用量に注意してください
