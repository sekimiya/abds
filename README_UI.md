# ABD Simulator v2 — UI操作ガイド

## 画面構成

画面は3つのエリアで構成されています。

1. **ヘッダー** — デッキ情報・作戦カード・メニューボタン
2. **リンクアビリティバー** — デッキ内のリンクアビリティ発動状況
3. **メインエリア** — 5ユニット（MS+PL）の編成・ステータス表示

---

## ヘッダー

### デッキ情報（左側）

| 表示 | 内容 |
|------|------|
| **Total Cost** | デッキ全体の合計コスト |
| **殲滅 / 制圧 / 防衛** | 各カテゴリのカード枚数 |
| **SQ発動承認** | SQ発動条件を満たしている場合に表示（ピンク） |
| **EB発動** | EB発動条件を満たしている場合に表示（オレンジ） |

### 作戦カード（中央）

- **メイン / サブ**: クリックで作戦カード選択画面を表示
- 選択済みの場合はサムネイルとカード名を表示、`×` で解除

### メニューボタン（右側）

| ボタン | 機能 |
|--------|------|
| **☰**（メニュー） | 右からスライドメニューを表示 |

---

## メニューパネル（☰ から開く）

### デッキ操作

| ボタン | 機能 |
|--------|------|
| **保存** | デッキ名を入力してブラウザに保存（localStorage） |
| **読込** | デッキ読込ダイアログを表示 |
| **共有** | 共有用URLをクリップボードにコピー |
| **デッキ投稿** | デッキ名・投稿者名を入力してサーバーに投稿 |
| **← 戻す** | 操作を元に戻す（Ctrl+Z） |
| **やり直す →** | 元に戻した操作をやり直す（Ctrl+Shift+Z） |
| **表示を整理** | ユニット列の高さを揃えて表示を整理 |
| **REC** | 現在のデッキ編成をスクリーンショット画像（PNG）でダウンロード |

### 地形選択

4つのボタンから地形を選択すると、ステータスバーに地形補正が反映されます。

- **地上** / **宇宙** / **砂漠** / **水中**
- もう一度押すと解除

### 画像キャッシュ管理

- **キャッシュ: X枚** — ブラウザに保存された画像数
- **管理** — キャッシュ作成（全カード画像をダウンロード）・全クリア

---

## デッキ読込ダイアログ

メニュー → **読込** で表示されるダイアログです。

### 保存済みデッキ

保存済みデッキが一覧表示されます。各デッキに **適用** / **削除** ボタンがあります。

### デッキコードインポート

共有されたデッキコードを貼り付けて **Import** でデッキを復元できます。

### 便利機能

| ボタン | 機能 |
|--------|------|
| **デッキクリア** | 全スロットを一括削除（作戦カードも解除） |
| **ランダム生成** | MS5枚・PL5枚をランダムに自動構築 |

### リンク指定ランダム生成

1. **リンク1** を選択（必須）
2. **リンク2** を選択（任意、リンク1と異なるものを指定）
3. **リンク指定ランダム生成** をクリック

指定したリンクアビリティが発動するようにカードを優先的に選び、残りの枠をランダムに埋めてデッキを構築します。

## メインエリア（デッキ編成）

5ユニット分のカラムが横並びで表示されます。各ユニットは上から順に以下の構成です。

### カード名

レアリティとカード名を左揃えで2行表示します。

- `U アリュゼウス` / `U シン・アスカ` のようにレアリティが先頭に表示
- EBカードはオレンジ、SQカードはピンク、それ以外は緑で色分け
- 横幅に入りきらない場合は `…` で省略

### コスト・地形適性

`TCOST 10 地:S 宇:A 砂:B 水:A` のようにユニットコストと地形適性を1行で表示。
選択中の地形に対応するバッジがハイライトされます。

### MS / PLスロット

| 操作 | 動作 |
|------|------|
| **空のスロットをクリック** | カード検索画面を表示 |
| **カード画像をクリック** | 表面⇔裏面の切り替え |
| **ホバー →「詳細」ボタン** | カード詳細モーダルを表示 |
| **`×` ボタン（右上）** | スロットからカードを除去 |

スロットにはカードの状態に応じてバッジが表示されます。

| バッジ | 色 | 条件 |
|--------|----|------|
| **SQSP** | ピンク | MSがSQUAD SPを持つ |
| **SQ** | ピンク | PLがSQスキルを持つ |
| **EB** | オレンジ | MSがECHOES BEATを持つ |

リンクアビリティ発動中のカードはスロット枠が緑色にハイライトされます。

### ステータスバー（機動 / 遠距 / 近距 / HP）

MS + PLの合算値をバーで表示。

| バー色 | 意味 |
|--------|------|
| 青 | 基礎ステータス |
| ピンク | リンクアビリティによるバフ |
| 緑 | 地形適性ボーナス |
| 赤ストライプ | 地形適性ペナルティ |

### MS / PL詳細セクション

カードセット後にスロット下部に表示されるOCRデータの詳細。

**MS詳細**:
- MSアビリティ（名前・発動条件・効果）
- 武装（主武装・副武装）
- SPアタック（威力・射程・効果）
- ECHOES BEAT（EB SP名・レベル・効果）
- 地形適性ランク
- 機体情報（カード番号・機体名・パイロット名・カテゴリ・コスト）

**PL詳細**:
- PLスキル（名前・発動条件・効果）
- SQスキル詳細（トリガー・効果・SQラッシュ・ゲージ）
- パイロット情報（カード番号・カテゴリ・コスト）

### リンクアビリティセクション

各ユニットが持つリンクアビリティと発動状況を表示。

- **発動** — 緑バッジ
- **X/Y** — 未発動（必要数に対する現在数）

---

## リンクアビリティバー（ヘッダー直下）

デッキ全体のリンクアビリティを横並びで表示。

- **発動中**: 緑枠・グロー付き
- **未発動**: グレー枠
- 各チップには名前・必要数・効果テキストを表示

---

## カード検索画面

スロットをクリック、またはキーボードショートカット `/` で表示。
左右2ペイン構成で、左にフィルター、右に検索結果をスクロール表示します。

### 左ペイン — フィルター

各フィルターグループは折りたたみ可能（タイトルクリックで開閉）。
フィルターが多い場合は左ペインをスクロールして操作できます。

#### 基本

| フィルター | 操作 |
|------------|------|
| **レアリティ** | M / C / R / SR / U / P / LE（複数選択可） |
| **カテゴリ** | 機動 / 近距離 / 遠距離 / 装甲 / 汎用 / 殲滅 / 制圧 / 防衛（単一選択、再クリックで解除） |
| **シリーズ** | シリーズ名ボタン（複数選択可） |
| **ブックマークカード** | ONにするとブックマーク済みカードを検索結果に追加（OR条件） |
| **イラストレーター** | ドロップダウン選択 |

シリーズボタンの枠色でSQ/EB収録を確認できます。

| 枠色 | 意味 |
|------|------|
| ピンク | SQ関連カードを収録 |
| オレンジ | EB関連カードを収録 |
| グラデーション | 両方を収録 |

カテゴリボタンも色分けされています。

| 色 | カテゴリ |
|----|----------|
| 赤 | 殲滅 |
| 青 | 制圧 |
| 緑 | 防衛 |

#### コスト・ステータス

- **コスト**: 範囲スライダー（0〜13）
- **ステータス**: 機動≥ / 遠距≥ / 近距≥ / HP≥（最低値指定）

#### 地形・属性（デフォルト折りたたみ）

- **地形タイプ + ランク**: 地上/宇宙/砂漠/水中 × S以上/A以上/B以上/C以上
- **OCRあり**: OCRデータのあるカードのみ表示

#### EB（オレンジ、デフォルト折りたたみ）

- **カテゴリ**: EB SP / EBスキル / EBリンク
- **EBレベル**: 1 / 2 / 3
- **EBSP効果**: 変身 / スタン / 撃破 / 貫通 / 範囲 / デバフ / バフ / HP回復 / 防衛無視
- **EB発動条件**: Lv上昇時 / 上昇毎 / Lv以上 / Lv到達時（PLのみ）
- **EBSP詳細表示**: ONにするとサムネイルにEBSP情報をオーバーレイ表示（MSのみ）
- **EBスキル表示**: ONにするとサムネイルにEBスキル情報をオーバーレイ表示（PLのみ）

#### SQ（ピンク、デフォルト折りたたみ）

- **カテゴリ**: SQSP / SQスキル / SQリンク / SQラッシュ
- **SQSP効果**: 変身 / スタン / 撃破 / 貫通 / 範囲 / デバフ / バフ / HP回復 / 防衛無視 / 支援攻撃（MSのみ）
- **SQゲージ**: 大 / 中 / 小（PLのみ）
- **SQ発動条件**: ロックオン / 戦艦・拠点 / 撃破 / ゲージ最大 / MSアビリティ / 出撃（PLのみ）
- **SQスキル効果**: 機動力 / 遠距離 / 近距離 / SP威力 / ダメ軽減 / 弱体無効 / 全味方（PLのみ）
- **SQSP詳細表示**: ONでサムネイルにSQSP情報をオーバーレイ表示（MSのみ）
- **SQスキル表示**: ONでサムネイルにSQスキル情報をオーバーレイ表示（PLのみ）

#### SP（青、MSのみ、デフォルト折りたたみ）

- **SP効果**: 変身 / スタン / 撃破 / 貫通 / 範囲 / デバフ / バフ / HP回復 / 防衛無視 / 必中

#### PLスキル（PLのみ、デフォルト折りたたみ）

- **スキル名**: ドロップダウンから選択
- **スキル効果**: 機動力 / 遠距離 / 近距離 / SP威力 / ダメ軽減 / 敵デバフ / 対戦艦・拠点 / SQゲージ / 全味方 / HP条件 / 弱体無効

#### テキスト検索

- **名前・番号で検索**: カード名またはカード番号で検索
- **カードテキスト検索**: アビリティ・スキル・武装などの全テキストから検索（スペース区切りでAND検索）

#### アクションボタン（画面下部に固定）

- **SEARCH**: フィルターを適用して検索実行
- **CLEAR**: 全フィルターをリセット

### 右ペイン — 検索結果

- カードサムネイルがグリッド表示（スクロールで全件表示）
- カードサイズは固定幅（110px）で安定表示
- ホバーで少し拡大、右下に「詳細」ボタン表示
- クリックでデッキスロットにカードをセット
- ブックマークボタン（★）でカードをブックマーク
- ブックマーク済みカードはテキストウィンドウが黄色に変化

### フィルター永続化

検索条件はブラウザに自動保存され、ページを閉じても保持されます。
**CLEAR** ボタンを押した時のみリセットされます。

## デッキ一覧ページ（decks.html）

### 左スライドメニュー（☰ から開く）

| 機能 | 説明 |
|------|------|
| **フィルター** | すべて / ブックマークのみ |
| **ソート** | 新着順 / いいね順 / ブックマーク順 |
| **期間** | 全期間 / 週間（7日） / 月間（30日） |

### デッキエントリ

各デッキには以下の情報が表示されます:
- デッキ名・投稿者名・投稿日時
- 作戦カード（メイン・サブ）
- 発動中リンクアビリティ（EB=オレンジ、SQ=ピンク、通常=グレー）

## デッキ投稿

### 投稿方法

1. v2 シミュレータでデッキを編成
2. メニュー（☰）→ **デッキ投稿** をクリック
3. デッキ名・投稿者名（任意）・削除パスワード（任意）を入力
4. **投稿** をクリック

投稿者名はブラウザに保存され、次回以降のデフォルト値になります。

### デッキ削除

投稿時に設定した削除パスワードで削除が可能です。

## デッキの保存・共有

### ブラウザ保存

1. メニュー（☰）を開く
2. **保存** をクリック → デッキ名を入力 → ブラウザのlocalStorageに保存

### デッキコード共有

1. メニュー（☰）を開く
2. **共有** をクリック → URLがクリップボードにコピー
3. 共有されたURLを開くと自動的にデッキが復元

### デッキ読み込み

1. メニュー（☰）→ **読込**
2. 保存済みデッキの **適用** をクリック、またはデッキコードを貼り付けて **インポート**

---

## 画像キャッシュ

カード画像はブラウザのIndexedDBにキャッシュされます。

1. メニュー（☰）→ 画像キャッシュの **管理**
2. **キャッシュ作成** で全カード画像をダウンロード（プログレスバー表示）
3. キャッシュ済み画像はオフラインでも表示可能

## よくある質問

### カード画像が表示されない

本アプリではカード画像をサーバーから配信していません。
初回利用時やブラウザのデータを消去した後は画像キャッシュが空のため、カード画像は表示されません。

メニュー（☰）→ 画像キャッシュの **管理** → **キャッシュ作成** を実行して、画像をブラウザにダウンロードしてください。

### OCRデータがないカードがある

OCR処理が未完了のカードは「未OCR」と表示されます。
これらのカードはステータスやアビリティ等の詳細情報が表示されませんが、デッキへのセットは可能です。

### フィルターがリセットされない

検索条件はブラウザに自動保存されます。
意図的にリセットしたい場合は、検索画面の **CLEAR** ボタンを押してください。
