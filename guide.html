ABD Simulator とは

「ARSENAL BASE deckbuilding simulator」は、アーケードカードゲーム ガンダムアーセナルベースのデッキ構築シミュレーターです。
MS（モビルスーツ）5枚 + PL（パイロット）5枚 + 作戦カード（メイン/サブ）でデッキを組み、 ステータスやリンクアビリティの発動状況をリアルタイムで確認できます。

本アプリはファン活動の一環として個人が制作したものであり、バンダイナムコエンターテインメントをはじめとする公式・関連企業とはいかなる関係もありません。

モバイル/デスクトップ両対応。PWA（Progressive Web App）としてホーム画面に追加すれば、アプリのように使えます。

iPhone / iPad（Safari）
1
Safari で本アプリのページを開く
2
画面下部の共有ボタン（四角に上矢印のアイコン）をタップ
3
「ホーム画面に追加」を選択
4
名前を確認して「追加」をタップ
Android（Chrome）
1
Chrome で本アプリのページを開く
2
画面上部のインストールバナー、またはアドレスバー右の「インストール」アイコンをタップ
3
バナーが表示されない場合は、右上のメニュー（︙）から「ホーム画面に追加」または「アプリをインストール」を選択
PC（Chrome / Edge）
1
Chrome または Edge で本アプリのページを開く
2
アドレスバー右端のインストールアイコン（モニターに矢印のアイコン）をクリック
3
「インストール」を選択
一度画像キャッシュを作成すれば、デッキ構築・ステータス計算などアプリの基本機能は完全オフラインで動作します。キャッシュの作成方法は画像キャッシュを参照してください。
デッキを組む

画面のカード枠をタップして、カードを配置していきます。

基本の流れ
1
画面上部のMS枠またはPL枠をタップしてスロットを選択
2
下部のカードピッカーから配置したいカードをタップ
3
ステータスとリンクが自動計算されます
作戦カード

画面上部の M（メイン）/ S（サブ）枠をタップすると作戦カードを選択できます。

カードの入れ替え・削除

配置済みのスロットをタップして別のカードを選べば入れ替え。 スロットを長押しすると削除できます。

並び順を整理

メニュー内の「並び順を整理」をタップすると、MSカードがカテゴリ順（殲滅 → 制圧 → 防衛）に自動整列されます。

カードを探す

カードピッカーでは複数の条件を組み合わせてカードを絞り込めます。

検索・フィルター
カード番号 カード名 レアリティ 作品シリーズ リンクアビリティ コスト範囲 ステータス範囲 地形適性 カテゴリ
カード検索（メニュー内）

メニューの「カード検索」を使うと、デッキ編集とは独立してカードを閲覧できます。 カード情報の確認やブックマーク登録に便利です。

ブックマーク

カードを長押しするとブックマークに登録できます。 メニューの「ブックマークカード」から一覧表示が可能です。

ステータスの見方

各ユニット（MS + PL）のステータスは以下の計算で求められます。

計算式

MS値 x 地形補正
+ MS Lvボーナス（作品Lv設定に基づく）
+ PL値
+ PL Lvボーナス（PLレベル設定に基づく）
x リンクバフ倍率
= 最終値（端数切り捨て）

表示ステータス
機動力 遠距離攻撃 近距離攻撃 HP
カード枠の下にユニットごとの合計ステータスが表示されます。タップで詳細を確認できます。
リンクアビリティ

デッキ内のカード構成が条件を満たすと、リンクアビリティが発動しステータスにバフがかかります。

バフ倍率

小アップ +10%  中アップ +20%

複数のリンクが発動した場合、倍率は乗算で適用されます。

条件の確認

画面上部のリンクバッジで発動状況を確認できます。 条件を満たしたリンクは緑、未達成はグレーで表示されます。 全リンク達成時は「FULL LINK」バッジが表示されます。

地形適性

メニュー内の「地形適性」で地形を選択すると、MSの地形ランクに応じた補正がステータスに反映されます。

地形の種類
なし（補正なし） 地上 宇宙 砂漠 水中
適性ランクと補正

MSカードの各地形に対する適性ランク（S/A/B/C/D）に応じて、ステータスに倍率補正がかかります。 ランクが高いほど有利な補正になります。

作品Lv / PLレベル設定

メニューの「作品Lv設定」から、作品ごと・パイロットごとのレベルを設定できます。 設定したレベルに応じてLvボーナスがステータスに加算されます。

作品補正

作品（シリーズ）単位で Lv 0〜30 を設定します。 作品ごとにMS側・PL側それぞれのボーナス型（バランス型/遠距離型/近距離型/HP型）が決まっており、 型に応じたステータスにボーナスが加算されます。

PLレベル

パイロット名単位で Lv 0〜30 を設定します。 同名の全PLカードに適用されます。

ゲーム内のレベルに合わせて設定すると、より正確なステータスをシミュレーションできます。
デッキの保存と共有
デッキ保存

メニューを開き、デッキ名を入力して「保存」をタップ。 保存したデッキはセレクトボックスからいつでも呼び出せます。

デッキ共有

「共有」ボタンでデッキコードを含むURLがクリップボードにコピーされます。 受け取った側はURLを開くだけでデッキが復元されます。

Twitter投稿

メニューの「Twitter投稿」で、デッキURLと一緒にツイートを作成できます。

デッキ管理
適用（ロード） 名変（リネーム） 削除 クリア（全リセット）
画像キャッシュ

カード画像をキャッシュすることで、オフラインでもカード画像を表示できます。

キャッシュの作成
1
メニューの「キャッシュ管理」をタップ
2
「すべてダウンロード」でカード画像を一括キャッシュ
3
完了後はオフラインでも画像が表示されます
キャッシュにはストレージ容量を使用します。不要になったら「キャッシュをクリア」で解放できます。
注意事項
画像キャッシュ機能は、公式サイトからカード画像をダウンロードしてお使いの端末に保存します。 ダウンロード時の通信はユーザーの端末から公式サイトへ直接発生します。利用は自己責任でお願いします。

また、本機能は開発者の判断により、予告なくアプリの更新で変更・削除される場合があります。あらかじめご了承ください。
その他の機能
スクリーンショット

メニューの「スクショモード」で、デッキのスクリーンショット用の見やすい専用レイアウトに切り替わります。

バッジ表示設定

メニューから各種バッジ（SP効果、EB、SQ、AB、レアリティ）の表示/非表示を切り替えられます。

ライトモード

メニューの切替ボタンで、ダークモードとライトモードを切り替えられます。

データ更新

メニューの「データ更新」で、カードデータを最新版に更新できます。新弾追加時などに使用してください。

デスクトップ版 / モバイル版 切替

メニューからもう一方のビューに切り替えられます。
