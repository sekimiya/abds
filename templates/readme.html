ABDS とは

ABDS（Arsenal Base Deck Simulator）は、ガンダムアーセナルベースのデッキ構築を 支援する非公式ファンツールです。カードの検索・閲覧やデッキの作成・保存・共有が行えます。

基本的な使い方

デッキシミュレーター (v2)

  1. トップページから 「デッキシミュレーター v2」 を開きます
  2. 左パネルのカードリストからカードを選択し、デッキに追加します
  3. ヘッダーのデッキ名を入力し、保存ボタンでデッキを保存できます
  4. デッキコードの生成・読み込みで他の人とデッキを共有できます

カード検索

  1. トップページから 「カード検索」 を開きます
  2. カード名、番号、シリーズなどで検索できます
  3. フィルタを組み合わせて絞り込みが可能です

デッキ一覧

  1. トップページから 「デッキ一覧」 を開きます
  2. 保存済みのデッキを閲覧・管理できます

カード画像について

本ツールではカード画像をサーバー上に保持していません。 画像キャッシュを作成しなくてもWebアプリの全機能は利用可能ですが、 カード画像を表示したい場合はユーザー自身の操作でキャッシュを作成する必要があります。

キャッシュの作り方

  1. デッキシミュレーター v2 を開きます
  2. ヘッダー右側のメニュー（≡）を開き、「画像キャッシュ」 セクションの 「管理」 ボタンをクリックします
  3. キャッシュ管理ダイアログで 「キャッシュ作成」 ボタンを押します
  4. 公式サイトからカード画像が取得され、お使いのデバイスのブラウザ（IndexedDB）にローカル保存されます
  5. 完了後、カード画像が表示されるようになります
ImageCache の仕組み
  • 画像はお使いのデバイスのブラウザ内（IndexedDB）にローカル保存されます
  • キャッシュ作成後は公式サイトへのアクセスは発生せず、ローカルキャッシュから高速に表示されます
  • キャッシュの削除は管理ダイアログの「全クリア」、またはブラウザの設定から行えます
  • カード枚数が多いため、キャッシュ作成時の通信量が大きくなる場合があります。Wi-Fi環境での実行を推奨します
画像キャッシュに関する重要事項

キャッシュ作成時、ユーザーのデバイスから公式サイトのカード情報に直接アクセスします。 公式サイトへのアクセスはユーザー自身のブラウザから行われるため、 画像キャッシュ機能の利用はすべて自己責任でお願いいたします。

デッキスクリーンショットの撮り方

作成したデッキを画像として保存・共有できます。

  1. デッキシミュレーター v2 でデッキを構築します
  2. ヘッダーの 「デッキ表示整理」 ボタンを押して、デッキの表示を整えます
  3. 「REC」 ボタンを押すと、現在のデッキ画面がスクリーンショットとして生成されます
  4. 画像ファイルが自動的にダウンロードされます
スクリーンショットの利用について

デッキスクリーンショットの利用（SNS等への投稿・共有を含む）は個人の裁量でお願いいたします。

UI操作方法 (v2)

画面構成

  • ヘッダー — デッキ情報（トータルコスト、クラス判定、SQ/EB状態）と作戦カード選択
  • 左パネル — カード検索・フィルタ
  • 中央エリア — 5ユニット構成のデッキ構築エリア
  • 右パネル — 検索結果のカードサムネイル一覧

カードの追加・削除

  1. 中央エリアの空きスロットをクリックすると、左パネルのカード検索が開きます
  2. 右パネルの検索結果からカードをクリックして追加します
  3. スロット上にマウスを合わせると表示される × ボタンでカードを削除できます

カード検索・フィルタ

左パネルで以下のフィルタを組み合わせて絞り込めます:

  • 基本 — レアリティ（M, C, R, SR, U, P, LE）、カテゴリ、シリーズ
  • コスト・ステータス — コスト範囲、機動力・遠距離・近距離・HPの最低値
  • 地形・属性 — 地形タイプ・ランクで絞り込み
  • EB / SQ / SP / PLスキル — 各種特殊能力カテゴリ・効果で絞り込み
  • テキスト検索 — カード名・番号・カードテキストで自由検索

メニュー（≡）

ヘッダー右端のメニューボタンから以下の操作が行えます:

  • 保存 — 現在のデッキをブラウザに保存
  • 読込 — 保存済みデッキの読み込み、デッキコードの貼り付けインポート
  • 共有 — デッキコードをクリップボードにコピー
  • 投稿 — デッキをサーバーに投稿
  • 戻す / やり直す — 直前の操作を取り消し・再実行
  • 表示を整理 — デッキの表示レイアウトを整える
  • 地形設定 — 地上 / 宇宙 / 砂漠 / 水中 を選択
  • 画像キャッシュ — キャッシュの管理画面を開く

作戦カード

ヘッダーの 「メイン」「サブ」 ボタンから作戦カードを選択できます。

デッキ読込ダイアログの便利機能

  • ランダム生成 — デッキをランダムに自動構築
  • リンク指定ランダム生成 — リンクアビリティを指定してランダム構築
  • デッキクリア — 全スロットを一括削除

注意事項

非公式ツールについて

本ツールは非公式のファンメイドツールです。株式会社バンダイナムコエンターテインメントとは一切関係ありません。

データの正確性

カードデータはOCR（画像認識）で取得しているため、一部のデータに誤りが含まれる場合があります。 正確な情報は公式サイトをご確認ください。

デッキデータの保存

デッキデータはサーバー上に保存されますが、永続的な保証はありません。 重要なデッキはデッキコードを控えておくことを推奨します。

推奨環境
  • PC: Chrome / Edge / Firefox 最新版
  • モバイル: Chrome / Safari 最新版
  • JavaScript が有効であること

よくある質問 (FAQ)

Q. カード画像が表示されません

キャッシュ作成を行わない場合はカード画像なしでアプリは動作します。 画像を表示したい場合は、メニューの画像キャッシュからキャッシュ作成を行ってください。

キャッシュ作成済みにもかかわらず表示されない場合は、ページをリロードしてみてください。 それでも表示されない場合は、ブラウザのキャッシュをクリアして再度キャッシュ作成をお試しください。

Q. デッキが保存できません

デッキ名が空の場合は保存できません。デッキ名を入力してから保存してください。

Q. デッキコードが読み込めません

デッキコードのコピー時に余分な空白や改行が含まれていないか確認してください。
