カード画像ダウンロード

カード画像の著作権はBANDAI/創通・サンライズ等の権利者に帰属します。
画像の取得・使用はユーザーの自己責任で行ってください。第三者への再配布は禁止です。

手順

  1. 下のいずれかの方法で画像をダウンロード
  2. アプリの「キャッシュ管理」→「画像インポート」でフォルダを選択
  3. 完了

おすすめ: Google Colab (スマホ対応)

Googleアカウントがあればスマホだけで完結します。PC不要。

  1. 下のボタンからColabノートブックを開く
  2. 「ランタイム」→「すべてのセルを実行」
  3. Googleドライブへのアクセスを許可
  4. 完了まで待つ (約15〜30分)
  5. Googleドライブの ABDS_CardImages/ に画像が保存される
  6. アプリの「画像インポート」でフォルダを選択
Google Colabで開く

Googleドライブに約700MBの空き容量が必要です。途中で止めても再実行で続きからDLされます。

方法4: iOS (ショートカットApp)

iPhoneの標準「ショートカット」アプリを使う方法です。

セットアップ

  1. 下の「ショートカット手順を表示」を押す
  2. 表示される手順に沿ってショートカットを作成
  3. 実行すると「ファイル」アプリの指定フォルダに画像が保存されます
  4. アプリの「画像インポート」でそのフォルダを選択
ショートカット手順を表示

ショートカット作成手順

  1. 「ショートカット」アプリを開く
  2. 右上の「+」で新規作成
  3. 「アクションを追加」→「Web」→「URLの内容を取得」を追加
  4. 以下のように設定:
    • URL: カード画像のURL (後述のリスト参照)
    • 方法: GET
    • ヘッダ: Referer = https://www.gundam-ab.com/cardlist/
    • ヘッダ: User-Agent = Mozilla/5.0
  5. 「ファイルを保存」アクションを追加 → 保存先を指定
  6. 「繰り返す」アクションで全カード分をループ
全カード(約7000枚)をショートカットで処理するとかなり時間がかかります。
シリーズごとに分割して実行することをおすすめします。

カード番号リスト:

card_numbers.json

方法5: Android (Termux)

Google Playから Termux をインストールしてください。

pkg install curl
mkdir -p ~/card_images
# 表面
curl -s https://YOUR_SITE/data/card_numbers.json | \
  python3 -c "import json,sys;[print(n) for n in json.load(sys.stdin)]" | \
  while read num; do
    curl -s -A "Mozilla/5.0" \
      -H "Referer: https://www.gundam-ab.com/cardlist/" \
      -o ~/card_images/${num}.jpg \
      "https://www.gundam-ab.com/images/cardlist/card/${num}.jpg"
    curl -s -A "Mozilla/5.0" \
      -H "Referer: https://www.gundam-ab.com/cardlist/" \
      -o ~/card_images/${num}_b.jpg \
      "https://www.gundam-ab.com/images/cardlist/card/${num}_b.jpg"
  done

ダウンロード後、アプリの「画像インポート」でフォルダを選択してください。
